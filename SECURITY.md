# Security and private reports

This repository holds proposals and text, not running software. Finding holes in the proposals is the point of the project, so report those in public, as [issues](https://github.com/opengravityai/opengravity/issues/new/choose).

Two things should not be posted in public:

- **A weakness in a live system or service.** That includes any service the register mentions, and any system run by someone else. Report it privately to whoever runs the system first. For systems we run, use the [contact form](https://opengravity.net/contact/).
- **Anything that would mainly help someone cause harm today**, such as working attack code or other people's personal data.

If you aren't sure which kind you have, contact us privately first.

If you send a private report and hear nothing within two weeks, open an issue saying only that you sent one, with no details, and we'll follow up.
